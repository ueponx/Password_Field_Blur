# パスワードフィールドぼかし (Password Field Blur)
![password-field-blur icon](images/icon128.png)
ウェブページ上のパスワードフィールドの入力状況を完全にぼかすためのChrome拡張機能です。

## 機能
- パスワードフィールドの文字数や入力状況が見えないように完全にぼかし
- 通常表示される「•••••」のようなドットも非表示
- トグルスイッチで簡単にオン/オフを切り替え
- 動的に追加されるパスワードフィールドにも自動的に適用
- フォーカス時には視覚的フィードバックあり

## 主な用途
| シナリオ | メリット |
|---------|---------|
| ハンズオン講習会 | 参加者に自分のパスワード入力が見られるリスクを軽減 |
| スクリーンシェア | オンライン会議でのパスワード入力時のプライバシー保護 |
| プレゼンテーション | デモ中のパスワード入力が観客に見えない |
| 公共の場所 | カフェなどでパスワードを覗き見されるリスクを軽減 |
| 録画デモ | 後から編集する必要がなく時間節約 |

## インストール方法
### 開発モードでのインストール
1. このリポジトリをクローンまたはダウンロード
   ```
   git clone https://github.com/yourusername/password-field-blur.git
   ```
2. Chromeブラウザで `chrome://extensions/` にアクセス
3. 右上の「デベロッパーモード」を有効化
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. ダウンロードしたフォルダを選択

## 使用方法
1. 拡張機能をインストール後、拡張機能のアイコンをクリック
2. ポップアップウィンドウでトグルスイッチをオンにする
3. これで全てのパスワードフィールドがぼかされます
4. 再度オフにするには、アイコンをクリックしてトグルをオフにします

## 技術的な仕組み
- すべての `input[type="password"]` 要素にCSSフィルタを適用
- 動的に追加される要素を検出するために `MutationObserver` を使用
- 拡張機能の状態は `chrome.storage.local` に保存
- 標準のパスワードフィールドの視覚的特性（ドット表示など）を上書き

## カスタマイズ方法
`styles.css` ファイルを編集することで、ぼかしの強さや見た目をカスタマイズできます：

```css
/* ぼかしの強さを調整 */
.password-field-blur {
  filter: blur(8px) !important; /* 数値を変更して調整 */
}

/* 背景色を変更 */
.password-field-blur {
  background: rgba(0, 0, 0, 0.3) !important; /* 色や透明度を変更 */
}

/* フォーカス時の枠線色を変更 */
.password-field-blur:focus {
  outline: 2px solid #007bff !important; /* 色や太さを変更 */
}
```

## 注意事項
- この拡張機能はあくまでも視覚的な隠蔽を行うものであり、セキュリティ対策ではありません
- 一部のウェブサイトでは、独自のスタイリングやJavaScriptによる処理により、完全にぼかしが機能しない場合があります
- パスワードマネージャなど他の拡張機能との競合が発生する可能性があります
